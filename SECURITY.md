# Security and privacy

Slide90 contains instructions and local utilities. It does not require network access or API keys.

## Report a vulnerability

Open a private GitHub security advisory when the repository is published. Do not disclose an exploitable issue in a public discussion first.

## Data handling

- Inspect source decks and screenshots before committing them.
- Remove names, logos, watermarks, file identifiers, and hidden speaker notes.
- Use synthetic examples by default.
- Review generated output before external distribution.
- Never put credentials, internal URLs, or customer data into examples or evaluation cases.
